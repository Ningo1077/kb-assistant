> 用途：结课答辩现场 6~8 分钟演示；也可作为交付验收的操作脚本

## 一、演示前 30 分钟 · 预检清单

- [ ] `curl http://127.0.0.1:8000/health` → `status=ok`，确认 `embed_provider` / `llm_provider` 是本次要演示的配置
- [ ] Ollama 已启动且 `qwen2.5:3b`、`bge-m3` 已 pull（真实模型演示）；若模型不可用，切回 `mock` 走兜底方案（§四）
- [ ] 前端 `http://localhost:5173` 能打开登录页；或桌面端安装包已安装、托盘图标可见
- [ ] 演示知识库里已有 2~4 份 `demo-files/` 文档且状态全为「✅ 就绪」
- [ ] 提前准备三个问题：一个有明确答案、一个多条款、一个资料里没写的（拒答）
- [ ] `docs/evidence/` 五份日志可随时打开，用作「已测试」举证
- [ ] `docs/prototype/index.html` 用浏览器打开备用标签页（断网/服务挂掉时兜底）
- [ ] 关闭无关窗口，浏览器缩放 100%，字号调到投影可见

> 演示文档均为 `demo-files/gen_demo_files.py` 生成的**虚构**数据（「云澜科技」），可现场声明，避免误会。

## 三、评委常问问题与回答要点

| 问题 | 回答要点 |
|---|---|
| 用了几种编程语言？ | **3 种编程语言**（HTML/CSS/JS(TS) 算一类、Python、Rust）+ SQL 操作数据库。按作业判分口径 SQL 不计入语言、TS 与 JS 同类合并，答辩统一用这个表述。 |
| 为什么选 PostgreSQL + pgvector？ | 关系数据与向量同库，一条 SQL 完成「按知识库过滤 + 向量近邻排序」，复用事务/备份/HNSW 索引；开发期通过 `VectorType` 方言抽象回退到 SQLite，零安装即可跑通。 |
| 前端为什么不用组件库？ | UI 全手写，便于控制 SSE 逐字渲染、引用角标、原文浮层等关键交互，也让设计→原型→实现链条可举证。 |
| 桌面端是不是套壳？ | 不是：托盘常驻、`Ctrl+Shift+K` 全局唤起、本地文件直读，还负责拉起并托管后端进程、卸载时按路径精确结束进程与备份数据。 |
| 怎么防止大模型编造？ | 三重约束：只用检索片段、每条结论强制标 `[n]`、无依据必须拒答；本地 3B 模型用 `temperature=0` 贪心解码；引用快照落库可回看。 |
| 为什么用 RRF？ | 向量与关键词两路分数尺度不同，RRF 只按排名融合 `1/(60+rank)`，无需调权重；纯向量对型号、专有名词不敏感，关键词正好补洞。 |
| 换模型要注意什么？ | 改 `EMBED_DIM`（bge-m3 是 1024）、重启后端（有 `lru_cache`）、`scripts/reindex_all.py` 重建全部索引；否则新旧维度混用会报形状不匹配。 |
| 数据会上传云端吗？ | 默认全本地（SQLite + Ollama），只有主动配置 `openai` 兼容云端服务时才会外发。 |
| 有什么没做完的？ | 坦率回答：前端「重新索引 / 删除会话」按钮未暴露（后端接口已实现）；真实本地模型完整生成约 10 秒级，需求文档「首字 <2s」应按 provider 区分计量；PostgreSQL 生产库实测未在本机做，部署手册给了验收步骤。 |

## 四、现场兜底方案

| 故障 | 立即切换 |
|---|---|
| Ollama 未启动 / 模型没拉下来 | 把 `.env` 改回 `EMBED_PROVIDER=hashing` `EMBED_DIM=512` `LLM_PROVIDER=mock`，重启后端，跑 `reindex_all.py`；回答会带「离线模拟回答」标记，但**链路、引用、流式全部可演示** |
| 后端起不来 | 打开 `docs/prototype/index.html`，完整演示登录/工作台/文档/流式问答/引用浮层，说明是设计阶段高保真原型（不发网络请求） |
| 前端构建失败 | 用 `frontend/dist/` 已构建产物 + 任意静态服务器；或直接用桌面安装包 |
| 桌面端无法安装 | 用 Web 端演示三个主要流程，托盘/快捷键改用 `src-tauri/src/main.rs` 代码 + 截图说明 |
| 投影分辨率低 | 浏览器缩放 125%，先关掉设计标注面板 |

> **无论哪种兜底，都不要现场临时改代码**。所有兜底路径都在部署手册中有对应命令。

## 五、交付验收清单（人工测试部分）

自动化测试覆盖不到的部分，用本清单人工验收：

- [ ] 安装包安装成功，首次启动自动拉起后端、窗口正常显示
- [ ] 托盘图标存在，双击可显示窗口
- [ ] `Ctrl+Shift+K` 可唤起/隐藏窗口
- [ ] 点「×」窗口隐藏而非退出，托盘「退出」才真正结束
- [ ] 退出后无残留 `uvicorn app.main:app` 进程
- [ ] 卸载询问是否保留数据，选择保留后 `文档\KB-Assistant-Backup\<时间戳>` 有备份
- [ ] 安装包内不含 `.env`、`app.db`、`uploads/`、`*.bak`
- [ ] 上传 20MB 以上文件、`.exe` 文件、空文件，均被拒绝且给出可读提示
- [ ] 上传扫描件 PDF，状态为「❌ 失败」并显示「需 OCR」原因
- [ ] 断网后仍能完成一次完整问答（本地模型配置）
- [ ] 刷新页面、重开应用后历史会话与引用仍完整

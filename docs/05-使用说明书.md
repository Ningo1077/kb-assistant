# 使用说明书 · 私有文档知识库问答助手

> 面向：最终使用者 / 现场演示人员（不需要看代码）
> 部署与安装请看 `docs/04-部署手册.md`；界面设计说明看 `docs/02-UI原型设计说明书.md`

---

## 一、它能做什么

把 PDF / Word / Markdown / TXT / CSV 导入自己的知识库，用大白话提问，系统只依据你的文档回答，**每条结论都标注来自哪份文件第几页**，点击角标还能看到原文片段。所有文档与模型都跑在本机，断网也能用。

界面长这样（左右分栏，两个 Tab）：

```
┌────────────┬──────────────────────────────────────┐
│ 知识库列表 │   [ 文档管理 ]  [ 智能问答 ]          │
│ ＋新建     │   …上传区 / 文档表格 / 对话区…        │
└────────────┴──────────────────────────────────────┘
```

## 二、五分钟快速上手

| 步骤 | 操作 | 看到什么 |
|---|---|---|
| 1 | 打开应用（网页端 `http://localhost:5173`，或桌面端双击图标） | 登录卡片 |
| 2 | 首次使用点「注册一个」，填邮箱 + 至少 6 位密码，点「注册并登录」 | 进入工作台 |
| 3 | 左侧点「＋ 新建知识库」，输入名称如「演示知识库」，回车 | 新库出现在左侧并自动选中 |
| 4 | 在「文档管理」页点「⬆ 选择文件上传」，或直接把文件拖进面板 | 文档行出现，状态从「⟳ 解析中 / 向量化中」变成「✅ 就绪」 |
| 5 | 切到「智能问答」，输入问题按 `Ctrl+Enter`（或点「发送」） | 回答逐字出现，带 `[1][2]` 角标与来源卡片 |

推荐先试试 `demo-files/` 里的演示文档（「云澜科技」等公司与数据均为虚构）。

## 三、账号

- **注册**：邮箱 + 密码（6~72 位）+ 可选昵称；邮箱重复会提示「该邮箱已注册」；
- **登录**：密码错提示「邮箱或密码错误」；登录状态保存在浏览器本地，有效期 7 天；
- **退出**：左下角「退出」，回到登录页；
- 账号只用于区分「谁的知识库」，数据全在本机数据库，不会上传云端。

## 四、知识库

| 操作 | 位置 | 说明 |
|---|---|---|
| 新建 | 左侧「＋ 新建知识库」 | 名称不能为空，回车或点「确认」 |
| 切换 | 点击左侧某个知识库 | 右侧标题与两个 Tab 内容随之切换；每个库显示「文档数 / 分块数」 |
| 删除 | 左下角「删除当前库」 | 会二次确认；**同时删除该库全部文档与向量，不可恢复** |

知识库之间是隔离的：在 A 库提问不会检索到 B 库的文档，别人也无法访问你的库。

## 五、文档管理

### 5.1 支持的类型与限制

| 项 | 规则 |
|---|---|
| 格式 | `.pdf` `.docx` `.md` `.txt` `.csv` |
| 单文件大小 | ≤ 20MB |
| 空文件 | 拒绝 |
| 多文件 | 可一次选多个，或拖拽多个进面板 |
| 扫描件 PDF | 无文本层，会入库失败并提示「需 OCR」——这是预期行为 |

### 5.2 上传后的状态

| 徽章 | 含义 | 你需要做什么 |
|---|---|---|
| ⟳ 等待中 / 解析中 | 正在解析文本、切分片段 | 等待，界面每 1.2 秒自动刷新 |
| ⟳ 向量化中 | 正在把片段转成向量 | 等待（真实模型下可能稍久） |
| ✅ 就绪 | 已可检索 | 直接去「智能问答」提问 |
| ❌ 失败 | 解析或向量化出错 | 行内会显示具体原因（如扫描件、模型不可用）；后端支持重新索引接口 |

### 5.3 两个实用特性

- **秒传去重**：同一知识库里内容完全相同的文件（哪怕改了文件名）不会重复解析入库，直接复用已有分块；
- **删除**：点该行「删除」，二次确认后删除文档记录、分块向量与磁盘上的原文件。

> 说明：当前版本的文档面板提供「删除」，重新索引由后端接口 `POST /reindex` 支持，界面按钮尚未提供（见测试报告 OBS-01）。遇到失败文档，可删除后重新上传。

## 六、智能问答

### 6.1 提问

- 输入框支持多行；`Ctrl+Enter`（Mac 为 `Cmd+Enter`）或点「发送」提交；
- 生成过程中显示「● 正在生成…」，发送按钮暂时禁用；
- 回答**逐字出现**（SSE 流式），不是等全部生成完才显示；
- 回答里的 **加粗** 是直接答案里的关键信息；与命中片段相关的词会高亮。

示例问题（配合演示文档）：

- 「温度超过多少度会触发告警？」
- 「年假有多少天？」
- 「采样周期是多少？」

### 6.2 看懂引用（这是本系统的核心）

回答中的 `[1]` 是可点击角标，气泡下方还有来源卡片，例如：

```
[1] 云澜智能音箱X1产品说明书.docx · 第1页
[2] 云澜科技员工手册.pdf · 第3页
```

点角标或来源卡片，会展开该片段的**原文内容**，并标明文件名与页码 —— 你可以据此核对答案有没有编造。刷新页面后再打开历史会话，引用仍然完整（引用快照已存库）。

> 如果资料里确实没有答案，系统会明确回答「资料中未提及该信息。」，而不是编一段看起来像答案的内容。

### 6.3 会话与反馈

| 功能 | 操作 |
|---|---|
| 新对话 | 顶部「＋ 新对话」或下拉选「— 新对话 —」 |
| 找回历史 | 顶部下拉选择历史会话，完整还原多轮问答（服务端保存，刷新不丢） |
| 多轮 | 在同一会话连续提问，系统会把最近几条**提问**用于理解「它」「这个阈值」这类指代，但不会照抄上一轮答案 |
| 回答质量反馈 | 回答下方显示「耗时 xxx ms」，旁边有「有用 / 无用」；点后变「已反馈」 |
| 删除会话 | 后端提供接口，当前版本界面未暴露删除按钮 |

## 七、桌面客户端特有操作

| 功能 | 操作 |
|---|---|
| 全局唤起 | 任意界面按 **`Ctrl+Shift+K`**，再按一次隐藏 |
| 最小化到托盘 | 点窗口右上角「×」只是隐藏，程序继续在托盘运行 |
| 显示窗口 | 双击托盘图标，或单击托盘菜单「显示窗口」 |
| 真正退出 | 托盘菜单「退出」（退出时会关掉它拉起的后端进程） |
| 拖文件入库 | 把本地文件拖进文档面板，桌面端可直接读取本地路径 |
| 卸载 | 「设置 → 应用 → 已安装的应用」/ 开始菜单 `Uninstall KB-Assistant` / 安装目录 `uninstall.exe` |
| 卸载时数据 | 交互卸载会**询问是否保留知识库数据**；选择保留会备份 `backend/data` 到 `文档\KB-Assistant-Backup\<时间戳>`；静默卸载默认保留 |

> 桌面端连的是**安装目录下**的后端。若想给它换模型，需要修改 `<安装目录>/backend/.env`，开发目录里的 `.env` 不影响它（见部署手册 §5.3）。

## 八、数据放在哪 / 隐私

| 内容 | 位置 |
|---|---|
| 数据库（用户、知识库、文档元数据、分块向量、会话、引用、反馈） | `backend/data/app.db`（开发版）／ `<安装目录>/backend/data/app.db`（桌面版） |
| 上传的原始文件 | `backend/data/uploads/` |
| JWT 随机密钥 | `backend/data/secret.key`（自动生成，不入库、不打包） |

文档不出本机；只有当你主动把 `LLM_PROVIDER` / `EMBED_PROVIDER` 配成云端 `openai` 兼容服务时，才会有数据发送到该服务。默认配置全流程本地。

## 九、常见问题（FAQ）

| 问 | 答 |
|---|---|
| 上传后一直「解析中」？ | 看后端日志与文档行的错误原因；多为扫描件 PDF 无文本层或模型服务未启动 |
| 回答里带「离线模拟回答」？ | 当前是 `LLM_PROVIDER=mock` 零依赖配置，只用于验证链路；按部署手册 §5 切换到 Ollama 才是真实问答 |
| 回答很慢？ | 本地 3B 模型完整生成约 10 秒级；可换更小/量化模型，或先用 mock 演示界面交互 |
| 换模型后检索报错？ | 向量维度变了，需重启后端并运行 `scripts/reindex_all.py` 重建全部索引 |
| 为什么答案没有引用？ | 没有命中任何片段；此时应回答「资料中未提及该信息。」 |
| 刷新后聊天没了？ | 从顶部会话下拉里选回历史会话；消息存在服务端 |
| 忘记密码？ | 定位为本机单机工具，暂无找回流程；开发版可直接重置本地数据库（会丢数据，先备份） |
| 能多人同时用吗？ | 定位为本机/局域网单机使用；公网多人使用需按部署手册 §10 补安全加固 |
| 界面和说明书不完全一致？ | 以 `docs/prototype/index.html` 原型与 `frontend/src/` 实际实现为准；本说明书按 v1.0.0 编写 |

## 十、已知限制

1. 前端未提供「重新索引」与「删除会话」按钮（后端接口均已实现）；
2. SQLite 回退方言没有 HNSW 索引，大数据量下建议切 PostgreSQL + pgvector；
3. 对话模型与向量模型共用 `LLM_BASE_URL`，不能分别指向两个不同服务；
4. 扫描件 PDF 需先做 OCR；DOCX 表格按行拼接为纯文本，复杂合并单元格可能失真；
5. 安装包内置 venv 依赖打包机 Python 路径，换机可能需要运行 `prepare-backend.bat` 重建。

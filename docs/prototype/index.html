UI 原型 v1.0 静态原型 · 不发网络请求 · 数据均为虚构演示数据

设计标注 / 交互要点

  1. 登录卡片：登录/注册双态，失败在卡内红条提示（I-01/02）
  2. 知识库侧栏：新建、切换、统计计数、删除与退出（I-03/04/13）
  3. 上传与拖拽区：多选上传、拖拽虚线高亮、格式与大小提示（I-05）
  4. 文档状态列：就绪/进行中/失败徽章，失败行内显示原因（I-06/07）
  5. Tab 切换：文档管理 ⇄ 智能问答，共用当前知识库（I-08）
  6. 流式消息区：meta→delta→done 逐字渲染、生成中禁用发送（I-09）
  7. 引用角标与来源卡：点击展开原文片段浮层（I-10）
  8. 耗时与反馈：done 后出现「有用/无用」，提交后变「已反馈」（I-11）
  9. 会话下拉：切换历史会话还原多轮问答（I-12）

桌面端 Ctrl+Shift+K 全局唤起、关闭最小化托盘由 Tauri 实现，原型不模拟（I-14）。
